Photo slider with scroll-snap

CSS · JS Intermediate 7 min read
fig. 01 — the finished buildhtml · css · js

A swipeable gallery built on native scrolling, with dot navigation.

No slider library needed. Scroll-snap gives you the swipe physics, and the only JavaScript is keeping the dots in sync with the scroll position.

What you'll build

  • Horizontal track with scroll-snap-type
  • Each slide snapping to the start edge
  • Dots that read the scroll offset
  • Arrow keys and buttons for people without touch

Files in the download

  • index.html
  • style.css
  • script.js

Before you start

You need a text editor and a browser — that's it. No package manager, no build step, no framework. Open index.html and the demo runs.

If you change something and it breaks, open the browser console first. Nine times out of ten the answer is a typo in a selector or a variable used before it exists.
