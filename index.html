05 / about

A phone, a text editor and too many tabs

I started this site in 2023 to keep my own notes in one place. It turned into a tutorial archive: the clock, the slider, the dark-mode toggle — each one written up with the code that made it work.

Most of it was written on Android, between classes, in editors that crash more than they should. That is why the downloads matter and why every demo stays small.

If a tutorial helped, tell me which one. If one broke, tell me faster.
