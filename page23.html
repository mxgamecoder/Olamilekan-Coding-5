Login form with a gradient button

HTML · CSS · JS Beginner 6 min read 26 Nov 2023
fig. 01 — the finished buildhtml · css · js

The hover treatment, plus the validation people forget to add.

A gradient sliding under a button is a nice trick, and it is two lines of CSS. The rest of the file is the part that makes the form usable.

What you'll build

  • Button with an overflow-hidden hover layer
  • Focus states that work with a keyboard
  • Length check with an inline result
  • No password stored anywhere on the page

Files in the download

  • index.html
  • style.css
  • script.js

Before you start

You need a text editor and a browser — that's it. No package manager, no build step, no framework. Open index.html and the demo runs.

If you change something and it breaks, open the browser console first. Nine times out of ten the answer is a typo in a selector or a variable used before it exists.
