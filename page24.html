Marquee text without ruining the page

CSS · Animation Beginner 4 min read 26 Nov 2023
fig. 01 — the finished buildhtml · css · js

A scrolling banner done with transforms and paused on hover.

The old <marquee> tag is gone, and that is fine — a duplicated track plus a transform does the same job without breaking layout or accessibility.

What you'll build

  • Duplicate the content so the loop has no gap
  • Translate the track by exactly half its width
  • Pause on hover and on focus
  • Turn the animation off for reduced-motion users

Files in the download

  • index.html
  • style.css

Before you start

You need a text editor and a browser — that's it. No package manager, no build step, no framework. Open index.html and the demo runs.

If you change something and it breaks, open the browser console first. Nine times out of ten the answer is a typo in a selector or a variable used before it exists.
